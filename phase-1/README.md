# Phase 1: Research, Product Definition, Copy, And Assets

This folder contains the implemented Phase 1 deliverables for Trust Lens.

Phase 1 is documentation and product foundation work. It does not include app code.

## Deliverables

| File | Purpose |
| --- | --- |
| `phase-1-plan.md` | Detailed implementation plan for Phase 1. |
| `product-foundation.md` | Product register, users, jobs, principles, and non-goals. |
| `copy-inventory.md` | Screen-by-screen product copy and cautious language rules. |
| `mock-data-inventory.md` | Complete mock data inventory needed by the frontend. |
| `evidence-boundaries.md` | Source, verification, assumption, and product-logic rules. |
| `asset-inventory.md` | Visual and UI asset requirements for the prototype. |
| `demo-script.md` | Walkthrough script for presenting the complete Trust Lens flow. |
| `phase-1-checklists.md` | Product, design, copy, accessibility, and handoff checklists. |
| `phase-1-completion-report.md` | Phase 1 acceptance status and next-phase handoff. |
